# FLEEXRS SENSI
App web responsivo de configuração de sensibilidade, com a marca @fleexrs.

## Teste
Abra `index.html` em um navegador.

## Android/iOS
O projeto pode ser empacotado posteriormente com um wrapper como Capacitor/Cordova ou usado como PWA.

Observação: este app apenas calcula, exibe e salva configurações de sensibilidade. Não injeta código nem altera o Free Fire.
